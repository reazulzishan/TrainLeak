Why

A model that scores 99% because the test set was already in training. Reviewers reject it; real users never get that score.

What it checks

Copies and same-template rows across train/test, repeated texts, a column that gives the answer away, SMOTE or scaling before the split.

Every finding

What it found with real numbers, why it matters, and code you can paste to fix it.
